hash map

noun · also hash table, dictionary, map

A table that finds any value from its key by turning the key into a slot number, so a lookup takes the same time with ten keys or a billion.

WATCH IT · THE EXPLAINER
PL. III▶ Big O, acted out58 s · the key “cat” drops into its bucket at beat 4
WHERE IT RUNS · TODAY
Redis keeps every key in one, which is why a lookup feels instant at any size. A Python dict and a JavaScript Map are hash maps. A database index can be one: PostgreSQL’s hash index.
⇄ [N] openings ask for Redis · the market
WHY IT WORKS · THE MATH

The key is turned into a number, and the number into one of the table’s slots, so finding it is one step, not a scan. When two keys land in the same slot that’s a collision; with n keys in m slots the table stays fast while n / m stays small, which is why it resizes as it fills.

LOOKUP O(1) ON AVERAGE · O(n) WHEN EVERY KEY COLLIDES
