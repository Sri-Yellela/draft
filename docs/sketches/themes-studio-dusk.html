Targets: body text 4.5 : 1; the large figures and headlines 3 : 1 (they're ≥ 24 px, so they count as large text); bars and the progress track 3 : 1 against their track. Every row in the registry's CONTRAST_PAIRS is checked by d91ThemeModule once Dusk is generated; this table covers only the pairs these screens show.

What you decide

  1. 1 · Shape and type: colours only, or colours + radii + type? What makes the screenshots look the way they do is mostly the 24 px corners, the huge tight headlines and the roomy spacing, not the colours. Today's theme module carries colours only (THEME_MODULE §5, "effects stay put", and that's why Studio has no radii either). So "colours + radii + type" adds a small second token axis: card / button radius, headline font, headline size, tracking and padding. It's built once in the shared components and is off for every existing theme, so they stay byte-identical. "Colours only" ships without that work, but you'd get the palette without the feel. Flip the second control to compare. Default: colours + radii + type.
  2. 2 · The headline font: Inter Tight or Manrope, both free (OFL). The site would self-host the file (one woff2, about 30 KB) so no page calls Google; or System UI, which needs no file. Only headlines and figures use it; body text stays the system font. Default: Inter Tight.
  3. 3 · Dusk Light's button: pale peach on a warm off-white barely reads as a button (its edge is about 1.3 : 1 against the page), though its label passes. A deep coral with a white label (5.35 : 1) reads clearly. Default: deep coral.
  4. 4 · The orange mark inside Dusk: the wordmark keeps draft's #FD4600, and peach is the interface's accent. In Dusk Light, orange on the off-white is 3.1 : 1, which is fine for a logo but would fail as text. Default: keep the mark orange.
  5. 5 · Ordinary bars: Studio draws ordinary bars in blue with orange for the top one. Dusk draws them in grey with peach for the top one (one accent, as in the screenshots). Default: grey + peach.
  6. 6 · Where it applies: the same per-surface choice as Studio (the app · the Admin pages · public pages) in Admin → System → Appearance, and an "Offer Dusk to users" switch, off by default. Documents are never themed.
