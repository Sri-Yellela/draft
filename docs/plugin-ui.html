/draft — the plugin: where the switches go

One direction matters: there is no "Sign in with OpenAI" button inside draft. The user adds draft's plugin inside ChatGPT; ChatGPT then sends them to draft's own consent screen (tab 4). So draft's job is to control and show the connection — the switch, the state, the revoke — and to meet the user where they are: at the résumé button, and in the chat. All numbers and names are samples.
