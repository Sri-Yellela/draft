Keyboard shortcuts

Two shortcuts, one for each half of the job. Press the first on a job posting to capture it into your job pool. Press the second on an application form you have already signed in to reach, and the answers you prepared in Draft are filled in for you to review. Draft never submits an application — you do.

Automatic capture

When this is on, a job posting you open on one of these sites is read by your browser, checked against your board, and added to it if it fits — you do not have to press anything. A page that is not a job posting is never sent. A posting that does not fit your board is not stored. Nothing is filled in or submitted for you. Turning it off removes the extension's access to these sites.

Shortcuts are set in Chrome's own shortcuts page, which is the only thing that can actually rebind one — an extension cannot reassign its own keys. This page used to record a custom combination itself, but that only worked while one of six job sites had focus, because it was implemented by a script running on those pages. Neither shortcut works that way now: each runs on whatever page you invoke it on, so the keys are Chrome's to own and they work everywhere. If one reads “Not set” above, Chrome declined the default — usually because another installed extension already claimed that combination — and assigning any free key there fixes it.
